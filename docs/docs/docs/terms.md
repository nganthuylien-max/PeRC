# Điều khoản sử dụng – PeRC

PeRC là đồ án môn học, cung cấp miễn phí để tham khảo và học tập.

Kết quả tính toán chỉ mang tính hỗ trợ; người dùng phải tự kiểm tra và chịu trách nhiệm khi dùng cho hồ sơ thiết kế thực tế.

Mỗi tài khoản có hạn mức sử dụng hằng ngày; quản trị viên có thể khoá tài khoản lạm dụng.
